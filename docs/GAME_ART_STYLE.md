# Game Art Style atlas — Forge pointer

**Source:** https://x.com/songsong/status/2113443243153338380  
**Site:** https://gameartstyle.loopyhop.com/  
**Decision:** **PROMPT/STYLE REFERENCE ONLY. No image copying.**

## What it is

A visual atlas of **37 game-art styles across 104 games**, with:

- style categories (paint & line, pixel & retro, shape & material, 3D & rendering)
- “what to look for” notes
- a **global art-direction prompt** per style
- links to official game sources

## Licence reality

The site states clearly:

> Images belong to their respective rights holders. Public availability is not a reuse license.

Do **not** download, trace, train on, or republish the screenshots. The prompt text can be used as a study/reference starting point; re-author it for the project.

## Forge use

1. Pick a style reference for the art bible.
2. Read the “what to look for” notes.
3. Use the global prompt as a **starting direction**, not a final asset spec.
4. Rewrite for the project’s genre, camera, palette, platform and readability.
5. Record the style name and URL in `ART_BIBLE.md`.
6. Generate original designs; never copy a game’s characters, logos or compositions.

## Good uses

- choosing an art direction when the brief is vague
- writing a global style prompt for all workers
- building a palette/material/motion vocabulary
- comparing “painterly” vs “cel-shaded” vs “pixel” approaches

## Bad uses

- using screenshots as textures, sprites, references to trace, or training data
- claiming a style is licensed for reuse
- copying a named game’s distinctive character or UI
- applying one filter over mismatched assets
