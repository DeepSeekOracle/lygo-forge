# GrokFilm — Forge pointer

**Source:** https://x.com/okapi_fukugyo/status/2113413804860244474  
**Site:** https://grokfilm.app  
**Decision:** **POINTER ONLY. No copying, no install.**

## What it is

A cinematic technique index for generative film:

- camera, lighting and editing techniques
- example reels
- prompt language written for Grok Imagine
- disciplines / skill tiers / moods

The post claims ~300 techniques.

## Licence caution

The site has no visible reuse licence for its example reels or prompt text. Treat it as:

- a **vocabulary and study reference**
- not a source of copy-paste prompts for client work
- not a source of footage, stills or training data

Re-author the technique in Forge’s own words and record the source.

## Forge use

Use it alongside `forge-camera-language` when:

- a director brief needs a named technique
- you need a shot/lighting/cut vocabulary
- you are comparing several approaches before a render
- you want to explain a look to a worker

## Forge rules

- One primary move per shot; name the technique, then write the concrete start/end state.
- Do not copy example prompts verbatim.
- Do not use the example reels as assets.
- Record technique name + URL in the shot note.
- Translate the idea into the local Wan/ComfyUI or Three.js pipeline.
- No paid Grok Imagine dependency is required for Forge.
