**Licence:** MIT

**Engine:** Godot 4.7.2 stable

## Path

```text
<FORGE_DIR>\tools\Pixelorama\Pixelorama-Windows-64bit\Pixelorama.exe
```

## Why it fits

- pixel-art layers, tilemaps and map creation
- palettes, gradients, selection and visual effects
- onion skin and frame animation
- sprite-sheet and PNG export
- 3D layers
- local, free, no account, no telemetry requirement

## Forge use

1. **2D Character Worker** generates or sources the base sprite/reference.
2. Open it in Pixelorama; clean pixels, build layers and palette, add animation frames.
3. Export PNG strips or individual frames into the project’s source/working folder.
4. Record canvas size, palette, frame tags, export path and Pixelorama version in the job note.
5. Technical Artist imports the sprite sheet and verifies scale/alpha/animation names.
6. Asset Pointer records source, licence, hashes and any external references.

## Limits

- Pixelorama is a **GUI application**; Forge does not claim a headless CLI.
- The distribution bundles Godot 4.7.2; do not mix its runtime with Forge’s engine assumptions.
- Do not overwrite source `.pxo` files; save versions.
- Lottie/3D-layer output is not a game-engine format by itself; export PNG/sprite sheets and verify.
- Pixel art generated by a model still needs a provenance/licence row.
