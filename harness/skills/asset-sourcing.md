# Asset Sourcing

## Rule zero

**No asset enters the build without a licence row.** Unknown source = not shippable.

## Preferred order

1. **Existing local library** — reuse and modify.
2. **CC0 / public domain** — Kenney, Quaternius, Poly Haven, AmbientCG, OpenGameArt CC0.
3. **Generated** — local image/model tools, with prompt, seed, model and review recorded.
4. **Commissioned / paid** — only with an explicit decision and receipt.

## Verify before download

- Author and source URL.
- Licence text and allowed uses (commercial, modification, attribution).
- File format, resolution/polycount, texture maps.
- Art-style match against `ART_BIBLE.md`.
- Hash (SHA-256) and local path.

## Good CC0 starting points

- [Kenney](https://kenney.nl/assets) — 2D/3D game kits, CC0.
- [Quaternius](https://quaternius.com/) — low-poly 3D, CC0.
- [Poly Haven](https://polyhaven.com/) — HDRIs/models/textures, CC0.
- [AmbientCG](https://ambientcg.com/) — PBR materials, CC0.
- [Awesome CC0](https://github.com/madjin/awesome-cc0) — index.
- [OpenGameArt](https://opengameart.org/) — **check each licence**, not the site.

## Rejection list

- Ripped game assets, fan art without permission, "found on Pinterest".
- Paid packs without a receipt.
- Fonts without a compatible licence.
- Music with unclear sync/streaming terms.
