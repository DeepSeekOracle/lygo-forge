# 3D Game Building

## Low-end first

- Target **60 FPS at 1280×720** on the low preset.
- Budget: ~90–140 draw calls, ~150k–300k triangles, 96–192 MB textures.
- One shadow-casting directional light; bake ambient and static shadows.
- No realtime GI, no SSR, no full-screen post on the low preset.
- LOD groups on repeated props; occlusion and frustum culling on.
- Static batching / GPU instancing before adding more set dressing.

## Modular kit

Build one kit: floor, wall, corner, doorway, prop A/B/C. Snap to a grid. A small kit reused well beats a large kit with broken scale.

## Readability

- One landmark per space.
- Light the path, darken the edges.
- Strong value contrast at the play distance; detail is for close-up.
- Test at the gameplay camera, not in the editor free camera.

## Pipeline

1. Grey-box scale and camera.
2. Traversal test with capsule.
3. Kit and collision.
4. Lighting mood.
5. Props and VFX.
6. Low preset and measurement.
7. Optimise, then add detail.
