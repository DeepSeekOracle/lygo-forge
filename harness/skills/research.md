# Research and Process References

These are the systems LYGO Forge adapts. Forge is our own implementation; no third-party runtime is bundled.

## Planning and delivery

- [BMad Method](https://github.com/bmad-code-org/BMAD-METHOD) — MIT. Right-sized delivery loop: clarify, plan, build, verify, learn; explicit decisions and durable context.
- [BMad Game Dev Studio](https://github.com/bmad-code-org/bmad-module-game-dev-studio) — MIT. Game-specific GDD, narrative, UX, technical architecture, epic production.
- [GitHub Spec Kit](https://github.com/github/spec-kit) — MIT. Constitution → specify → plan → tasks → implement → converge; artifacts and checklists.
- [Taskmaster](https://github.com/eyaltoledano/claude-task-master) — MIT with Commons Clause. Its dependency-aware task discipline inspired ours; the code is **not** copied or bundled, and Forge is not a competing task product.
