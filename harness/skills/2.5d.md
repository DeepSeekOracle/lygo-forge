# 2.5D Game Building

2.5D means **2D rules on a 3D stage**, not a 3D game with a locked camera.

## Rules

- Gameplay positions live on a 2D plane; the third axis is presentation or depth.
- Pick one camera pitch and one field of view per level.
- Define a **sorting policy**: y-sort, layer, or depth buffer. Do not mix silently.
- Transparent objects sort last and can break; keep characters and foliage on explicit layers.
- Shadows anchor sprites to the floor; without contact shadows the depth reads wrong.
- The player must read the playable plane before the scenery.

## Low-end approach

- One directional light + baked ambient; no realtime GI.
- Parallax via a few camera-locked planes, not many 3D props.
- Use billboards for distant foliage and crowds.
- Put a hard cap on transparent overdraw; test at 1280×720.
- Keep post optional; ship a no-post low preset.

## Pipeline

1. Blockout the playable plane.
2. Add camera and a scale reference.
3. Add one modular set kit.
4. Add character sprites and contact shadows.
5. Add atmosphere only after gameplay reads.
