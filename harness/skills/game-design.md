# Game Design Core

## The four questions

1. What does the player do in the first 15 seconds?
2. What changes in the 5-minute loop?
3. What is the session goal, and why stop?
4. What does failure cost, and what does mastery look like?

If any answer is a genre label instead of a verb, the design is not ready.

## Loop layers

| Layer | Time | Must answer |
|---|---|---|
| Moment | 0–10 s | Is the input readable and satisfying? |
| Encounter | 30–90 s | What decision does the player make under pressure? |
| Run / level | 5–20 min | What build, route or risk is being shaped? |
| Session | 20–60 min | What is the reason to start and the reason to stop? |
| Meta | days | What persists, and is it earned rather than rented? |

## Pillars

A pillar is a decision filter, not a slogan.

Example: "Readable chaos" → test: a new player can name the biggest threat on screen within one second.

Write three pillars and one **non-goal** for each. If a feature does not serve a pillar, it needs a decision record, not a silent addition.

## Scope ladder

1. **Toy** — one verb, one screen, no fail state.
2. **Slice** — one complete loop, one level, placeholder art, real feedback.
3. **Vertical slice** — the intended look and feel in one representative level.
4. **Production** — content built in repeatable tasks.
5. **Release** — packaging, QA, credits, known issues.

Do not start at 4. A vertical slice that is not fun is a warning, not a content problem.

## MDA / feedback

- **Mechanics** — rules and numbers.
- **Dynamics** — what emerges when played.
- **Aesthetics** — the feeling.

For every mechanic write the intended dynamic and the feedback that teaches it (animation, sound, camera, HUD). If the player cannot perceive the rule, the rule does not exist.

## Balance

- Show formulas and ranges.
- Set one baseline: time-to-kill, time-to-die, income per minute.
- Change one variable at a time.
- Define a measurement: a test case or a recorded playtest.
- Keep a "feel" constant separate from a "balance" constant.

## Onboarding

Teach with space, not a wall of text:

1. Safe space to move.
2. One threat with a clear tell.
3. One reward that requires the new verb.
4. A checkpoint before the first real test.
